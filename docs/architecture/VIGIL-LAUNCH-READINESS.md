# Launch readiness

Internal launch checklists and gap inventories are **not published** in this repository.

Open-source contributors should use:

- [`CLAUDE.md`](./CLAUDE.md) — product constraints and engineering rules
- [`DEPLOYMENT.md`](./DEPLOYMENT.md) — how to run and deploy a Vigil instance
- [`DESIGN-SYSTEM.md`](./DESIGN-SYSTEM.md) — UI standards

Operators maintain launch readiness privately. Do not treat the absence of a public checklist as a security disclosure.
