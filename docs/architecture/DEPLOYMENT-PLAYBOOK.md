# Multi-country deployment

High-level: Vigil is config-driven. Change `src/config/crisis.config.ts` (bounds, hotlines, partners, languages) and redeploy for a new crisis instance.

Detailed go/no-go gates, archetype feed matrices, and operator capacity rules are **internal ops material** and are not published here.

For setup steps (Supabase, Vercel, DNS, env vars), see [`DEPLOYMENT.md`](./DEPLOYMENT.md).
